🔑 Connecting Your Live API Credentials

          
All keys are securely stored in your local .env file. Follow the steps below for each platform:


          

            

              
1. Shopify Admin API

              
    
                
  1. Open Shopify Admin > Settings > Apps and sales channels > Develop apps.
    2. 
                
  2. Create a custom app named Araadhya Hub.
    3. 
                
  3. Grant Admin API scopes: read_products, write_products, read_orders, write_orders, read_inventory, write_inventory.
    4. 
                
  4. Install app & copy Admin API access token into SHOPIFY_ADMIN_ACCESS_TOKEN.
    5. 
              

            


            

              
2. Razorpay

              
    
                
  1. Log in to Razorpay Dashboard.
    2. 
                
  2. Go to Account & Settings > API Keys.
    3. 
                
  3. Generate Key ID & Secret and put them into RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET.
    4. 
                
  4. Under Webhooks, add your webhook URL: https://YOUR_DOMAIN/webhooks/razorpay.
    5. 
              

            


            

              
3. Meta (WhatsApp & Instagram & Facebook)

              
    
                
  1. Visit Meta for Developers.
    2. 
                
  2. Create an App (Type: Business).
    3. 
                
  3. Add WhatsApp and copy your Phone Number ID & Permanent Access Token.
    4. 
                
  4. Add Instagram Graph API for DM automation.
    5. 
                
  5. Configure Webhook callback URL: https://YOUR_DOMAIN/webhooks/meta with verify token.
    6.
